A tiny greeting for your iOS app

SAMPLE POSTSWIFT2 MIN READ
TL;DR

A little personal touch goes a long way. Let's turn an optional name into a greeting without making things complicated.

This is a sample sleeper: a quick look at how posts and Swift code will feel here. Small idea, a few lines of code, and something you can try.

1. Start with a greeting

A function keeps the message in one place. If there's no name yet, give your visitor a friendly fallback.

SWIFT
// A little hello goes a long way.
func greeting(for name: String?) -> String {
    let displayName = name ?? "Sleeper"
    return "Hey, \(displayName)!"
}

let message = greeting(for: "Super Sleeper")
print(message) // Hey, Super Sleeper!

2. Give empty names some love

An empty string is still a value, so it won't use the fallback above. Check for it before building the message.

SWIFT
func greeting(for name: String?) -> String {
    guard let name, !name.isEmpty else {
        return "Hey, Sleeper!"
    }

    return "Hey, \(name)!"
}

greeting(for: nil)   // Hey, Sleeper!
greeting(for: "")    // Hey, Sleeper!
greeting(for: "Ash") // Hey, Ash!

Sleeper tip: Try the missing-name case first. That's where the small details tend to hide.

3. Keep it small

That's the whole trick: one function, a sensible fallback, and a greeting with a little personality. Now back to the late-night coding.
